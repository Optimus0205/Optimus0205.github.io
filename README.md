# Ashutosh Singh — Recruiter Portfolio

A single-page recruiter-facing portfolio built as a lightweight static website.

## Files

- `index.html` — complete portfolio; no build step or framework required.

## Run locally

Open `index.html` in a browser.

## Deploy

### GitHub Pages
1. Create a new repository.
2. Upload `index.html` to the root of the `main` branch.
3. In **Settings → Pages**, deploy from the `main` branch and `/root` folder.

### Netlify / Vercel
Drop the folder into a static-site deployment. No npm install is required.
